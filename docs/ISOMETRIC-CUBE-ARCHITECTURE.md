# Isometric Cube Architecture — Executive GitHub Profile

The previous abstract crystalline and Blender-monument experiments are retained as historical assets, but are no longer the active README visual language. The active direction is a large-scale **isometric cubic architecture**, inspired by the reference's use of projected three-face blocks and native SVG motion, but built as original compositions for this executive profile.

## Art direction

- Monumental modular cubes, not decorative trophies, abstract shards, toy icons, or scattered particles.
- Every block uses a consistent dimetric/isometric projection with three separately shaded visible faces.
- Directional face gradients, machined inset seams, restrained edge glints, and soft architectural shadows provide depth.
- Palette: deep midnight navy, indigo, cobalt, cyan, teal, amethyst, and restrained champagne-gold.
- Motion is deliberately slow: a small independent vertical easing and a light pass along cube edges. No frantic spins or bouncing.
- Desktop and mobile layouts are composed separately so the large cube structures remain legible and never clip.
- Reduced-motion users receive separate still SVGs.
- No external image host, JavaScript, or copied reference artwork.

## Four original compositions

1. **Hero:** an executive nameplate balanced with a large nine-block cubic skyline/architecture.
2. **Leadership & Ventures:** four substantial color-coded modular constructions for Saltrixma, SMI, Flunex, and scholarship work.
3. **Featured Systems:** four distinct block assemblies for QADHA, MIYTO Smart Rooms, SMI Operations, and AIU Smart HR.
4. **Capabilities:** an eight-module cubic intelligence structure with the eight disciplines arranged as clean editorial labels.
