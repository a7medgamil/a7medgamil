### Strategy sets direction. Systems make it executable.

I work at the intersection of **institutional leadership, product direction and technology delivery**. As **CEO of Saltrixma LLC** and **Founder & Managing Director of Superior Multiskills Institution (SMI)**, I focus on making complex work operational: defining the problem, establishing the operating model, guiding implementation and examining what is actually delivered.

A product is not just an interface. An institution is not just a set of departments. Both need clear decisions, accountable workflows and systems people can use.

**MIYTO Smart Rooms** — *Learning operations and product governance*  
Directed the design of structured audio-practice rooms: level-aware matching, timed sessions, attendance rules and supervisor intervention. The publicly inspectable lab is a **fictional simulation** of selected room-state decisions—not the live audio infrastructure.  
[Case study](https://github.com/a7medgamil/miyto-smart-rooms-showcase) · [Original runnable simulation](https://github.com/a7medgamil/miyto-smart-rooms-showcase/tree/main/demo/room-state-lab) · [26 tests / CI](https://github.com/a7medgamil/miyto-smart-rooms-showcase/actions/runs/44894982610)

**SMI Digital Operations** — *Institutional transformation*  
Defined connected academic and administrative workflows across student access, registration, attendance, assessment and institutional oversight. A separate synthetic case lab demonstrates workflow rules without exposing learner records.  
[Operating model](https://github.com/a7medgamil/smi-digital-operations-showcase) · [Original operations lab](https://github.com/a7medgamil/smi-digital-operations-showcase/tree/main/demo/operations-case-lab) · [39 tests / CI](https://github.com/a7medgamil/smi-digital-operations-showcase/actions/runs/44895321053)

**QADHA Platform** — *Consumer product direction*  
Directed the product structure for a social-video and challenge concept, including competition rules and the systems needed to operate it. The public battle-rules lab is independent of private application code; it does **not** represent live video, payments or a production launch.  
[Product case study](https://github.com/a7medgamil/qadha-platform-showcase) · [Original rules lab](https://github.com/a7medgamil/qadha-platform-showcase/tree/main/demo/battle-rule-lab) · [36 tests / CI](https://github.com/a7medgamil/qadha-platform-showcase/actions/runs/44896934520)

## 03 / Evidence, not adjectives

The public repositories above contain **original, executable examples with automated checks**. They demonstrate selected technical rules and delivery discipline; private operational source, student data and confidential company materials stay private.

**Academic work:** [AIU Smart HR](https://github.com/a7medgamil/aiu-smart-hr-showcase) documents an academic HR-system design with fictional interface previews. It is **not** presented as a deployed AI model or a working recruitment service.

**Working method:** define the operating problem → establish ownership and rules → coordinate implementation → validate behavior → improve the system.

**Technical context:** JavaScript / TypeScript · Node.js · PHP · React / React Native · SQL · Cloudflare · automated testing and delivery workflows. Technologies describe documented project context, not a claim of expertise in every tool.
